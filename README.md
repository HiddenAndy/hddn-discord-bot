# HDDN Discord Bot

청소 구역 추첨, 점심 메뉴, 채널별 모임 기능을 제공하는 디스코드 봇입니다.

## 빠른 시작

Node.js 18 이상이 필요합니다. 현재 개발 기준은 Node.js 20입니다.

```bash
npm install
cp .env.example .env
npm run commands:register # 명령어 추가, 변경 시
npm start
```

첫 실행 시 `src/data/store.json`의 현재 데이터를 초기값으로 사용해 `src/data/store.sqlite`를 만듭니다. 이후 운영 데이터는 SQLite 파일에 저장됩니다.

## 구조

- `src/index.js`: 디스코드 클라이언트 생성과 인터랙션 라우팅
- `src/commands/`: 슬래시 명령어 정의와 실행 핸들러
- `src/config/`: 환경 변수와 런타임 설정
- `src/data/`: 초기 데이터와 SQLite 저장소
- `src/services/`: 저장소를 변경하는 업무 로직
- `src/interactions/`: 버튼, 선택 메뉴, 모달 인터랙션 핸들러
- `src/schedules/`: 주간 자동 실행 작업
- `src/ui/`: 버튼 패널 같은 디스코드 UI 메시지 조립
- `src/utils/`: 날짜, 경로, 권한 같은 공통 유틸리티

## 디스코드 봇 만들기

1. Discord Developer Portal에서 새 Application을 만듭니다.
2. Bot 탭에서 봇을 생성하고 `Token`을 복사합니다.
3. OAuth2 > URL Generator에서 `bot`, `applications.commands` scope를 체크합니다.
4. Bot Permissions는 최소 `Send Messages`, `Use Slash Commands`, `Attach Files`를 체크합니다.
5. 생성된 URL로 봇을 서버에 초대합니다.

## 환경 변수

`.env.example`을 복사해서 `.env`를 만들고 값을 채웁니다.

필수 값:

- `DISCORD_TOKEN`: Bot Token
- `DISCORD_CLIENT_ID`: Application ID
- `DISCORD_GUILD_ID`: 서버 ID
- `CLEANING_CHANNEL_ID`: 청소 명령어와 자동 추첨 패널을 사용할 채널 ID
- `GATHERING_CHANNEL_IDS`: 모임 채널 ID 목록. 쉼표로 구분. 비워두면 모든 채널 허용

서버/채널 ID는 Discord 설정에서 개발자 모드를 켠 뒤 서버나 채널을 우클릭해서 복사할 수 있습니다.

## 명령어

청소:

- `/청소관리 설정패널`: 청소 구역과 스케줄을 관리하는 관리자 패널을 엽니다.
- `/청소테스트`: 청소 추첨 패널과 마감 후 안내처럼 테스트가 필요한 기능을 확인합니다. 관리자 전용입니다.
- `/청소 선호구역`: 본인 선호 카테고리 1~2개를 설정합니다.
- `/청소 선호확인`: 본인의 선호 카테고리를 확인합니다.
- `/청소 결과보기`: 이번 주 배정 결과를 확인합니다.

모임:

- `/모임설정`: 현재 채널의 모임 설정 패널을 엽니다. 관리자 전용입니다.
- `/모임테스트`: 투표 결과 보기, 투표 결과 공지 기능을 테스트합니다. 관리자 전용입니다.
- `/참여`: 현재 채널의 모임에 참여합니다.
- `/신청취소`: 현재 채널의 모임 참여를 취소합니다.
- `/현황`: 현재 채널의 모임 일정, 후보별 표 수, 참가자를 본인에게만 표시합니다.

기타:

- `/명령어갱신`: 현재 봇 코드 기준으로 서버 슬래시 명령어를 다시 등록합니다. 관리자 전용입니다.
- `/인원관리`: 봇 공통 인원과 Discord ID 연결을 관리합니다. 관리자 전용입니다.
- `/점심 추천`: 아직 준비 중 안내를 표시합니다.
- `/점심테스트`: 점심 기능 테스트 패널을 엽니다. 관리자 전용입니다.

자동완성:

- `/청소 선호구역`의 `1순위`, `2순위`: 활성 청소 카테고리 목록

## 권한과 채널 제한

관리자 전용 명령은 `/명령어갱신`, `/인원관리`, `/청소관리`, `/청소테스트`, `/모임설정`, `/모임테스트`, `/점심테스트`로 분리되어 있습니다.

- `/명령어갱신`: Discord 관리자 권한을 가진 사람에게만 기본 표시됩니다.
- `/인원관리`: Discord 관리자 권한을 가진 사람에게만 기본 표시됩니다.
- `/청소관리`: Discord 관리자 권한을 가진 사람에게만 기본 표시됩니다.
- `/청소테스트`: Discord 관리자 권한을 가진 사람에게만 기본 표시됩니다.
- `/모임설정`: Discord 관리자 권한을 가진 사람에게만 기본 표시됩니다.
- `/모임테스트`: Discord 관리자 권한을 가진 사람에게만 기본 표시됩니다.
- `/점심테스트`: Discord 관리자 권한을 가진 사람에게만 기본 표시됩니다.
- `/청소`: 일반 청소 기능입니다.
- `/참여`, `/신청취소`, `/현황`: 채널별 모임 기능입니다.

Discord에서 채널마다 보이는 명령어를 제한할 수 있습니다.

1. 서버 설정으로 이동합니다.
2. `연동` 또는 `Integrations` 메뉴를 엽니다.
3. 이 봇을 선택합니다.
4. `명령어` 또는 `Commands` 목록에서 원하는 명령어를 선택합니다.
5. 역할, 멤버, 채널별로 허용 또는 차단을 설정합니다.

예시:

- 모임 채널에는 `/모임설정`, `/모임테스트`, `/참여`, `/신청취소`, `/현황`만 허용
- 청소 채널에는 `/청소`, `/청소관리`, `/청소테스트`만 허용
- 관리자용 채널에는 `/명령어갱신`, `/인원관리` 허용
- 일반 채널에는 봇 명령어 전체 차단

주의: Discord는 세부 서브명령어가 아니라 `/청소`, `/청소관리`, `/참여` 같은 상위 명령어 단위로 표시 권한을 관리합니다.

봇 코드에서도 채널 제한을 한 번 더 검사합니다.

- `CLEANING_CHANNEL_ID`가 아닌 채널에서는 `/청소`, `/청소관리`, `/청소테스트`가 실행되지 않습니다.
- `/명령어갱신`은 채널 제한을 받지 않고 Discord 관리자 권한만 검사합니다.
- `/인원관리`는 청소 채널 제한을 받지 않고 Discord 관리자 권한만 검사합니다.
- `GATHERING_CHANNEL_IDS`에 없는 채널에서는 `/모임설정`, `/모임테스트`, `/참여`, `/신청취소`, `/현황`이 실행되지 않습니다.

## 명령어 갱신

새 슬래시 명령어를 추가하거나 이름/설명을 바꾼 뒤에는 Discord 서버에 명령어를 다시 등록해야 합니다.

```bash
npm run commands:register
```

운영 중에는 관리자 전용 명령어로도 갱신할 수 있습니다.

```text
/명령어갱신
```

주의:

- `/명령어갱신` 자체를 처음 추가한 배포에서는 서버에서 `npm run commands:register`를 한 번 실행해야 합니다.
- 이후에는 새 코드를 배포하고 봇을 재시작한 뒤 `/명령어갱신`을 실행하면 됩니다.
- 이 명령은 현재 실행 중인 봇 코드에 포함된 명령어 목록을 Discord에 등록합니다.

## 청소 운영

매주 설정된 요일/시간에 `CLEANING_CHANNEL_ID` 채널로 추첨 버튼이 올라갑니다. 기본값은 월요일 12:55입니다.

- 추첨 버튼은 채널에 공개로 보이고 모두 클릭할 수 있습니다.
- 등록된 활성 인원만 실제 추첨할 수 있습니다.
- 추첨 패널은 생성 후 30분 동안만 유효합니다.
- 30분이 지난 뒤 버튼을 누르면 본인에게만 추첨 종료 안내와 남은 구역 목록이 표시됩니다.
- 버튼을 누른 사람만 즉시 배정됩니다.
- 이미 이번 주에 뽑은 사람은 다시 뽑을 수 없습니다.
- 이미 배정된 구역은 다시 나오지 않습니다.
- 디스코드 유저 ID가 연결된 활성 인원이 활성 청소 구역보다 많으면, 초과 인원 수만큼 면제자를 랜덤으로 뽑습니다.
- 추첨 패널 메시지에 면제자 목록이 함께 표시되고, 면제자가 버튼을 눌러도 추첨되지 않습니다.
- 선호 구역은 35% 확률로 시도합니다.
- 선호 구역에 실패하거나 남은 선호 구역이 없으면 랜덤 배정됩니다.
- 공개 채널에는 누가 어떤 구역을 뽑았는지 표시됩니다.
- 배정 이미지가 있으면 버튼을 누른 사람에게만 개인 응답으로 보입니다.

구역별 이미지를 쓰려면 이미지를 `assets/cleaning-zones/`에 넣고 `/청소관리 설정패널`의 구역 수정 모달에서 이미지 경로를 입력합니다.

예시:

```text
assets/cleaning-zones/dust-a.png
```

이미지 경로가 없거나 파일을 찾지 못하면 개인 응답에는 텍스트만 표시됩니다.

## 청소관리 패널

관리자는 청소 채널에서 아래 명령어로 설정 패널을 열 수 있습니다.

```text
/청소관리 설정패널
```

패널에서 할 수 있는 일:

- `요약`: 활성 인원/구역 수와 카테고리별 구역 수 확인
- `구역`: 구역 목록 확인, 구역 추가, 기존 구역 선택 후 수정
- `선호구역`: 인원별 선호 청소 카테고리 확인과 수정
- `스케줄`: 청소 추첨 패널 자동 게시 요일/시간 확인과 변경
- `새로고침`: 최신 설정 다시 표시

구역 수정 흐름:

1. `구역` 탭으로 이동합니다.
2. 아래 선택 메뉴에서 수정할 항목을 고릅니다.
3. `선택한 구역 수정` 버튼을 눌러 모달을 엽니다.
4. 기존 데이터가 채워진 모달에서 값을 수정합니다.
5. 저장하면 설정에 반영됩니다.

선호구역 수정 흐름:

1. `선호구역` 탭으로 이동합니다.
2. 선택 메뉴에서 수정할 인원을 고릅니다.
3. `1순위 선택`, `2순위 선택` 메뉴에서 원하는 활성 카테고리를 고릅니다.
4. 선택 즉시 저장되고 패널이 최신 선호구역으로 갱신됩니다.

`없음`을 선택하면 선호구역을 비울 수 있습니다. `1순위 선택`에서 `없음`을 고르면 해당 인원의 선호구역 전체가 제거되고, `2순위 선택`에서 `없음`을 고르면 2순위만 제거됩니다.

## 테스트 패널

관리자 전용 테스트 명령어는 실제 운영 패널을 덮어쓰지 않고 새 메시지로 결과를 보여줍니다.

- `/청소테스트`: 추첨 패널 게시, 내 추첨 실행, 결과 요약, 마감 안내를 확인합니다.
- `/모임테스트`: 투표 메시지 게시, 결과 미리보기, 결과 채널 공지, 현황 요약을 확인합니다.
- `/점심테스트`: 점심 추천 준비 중 응답을 확인합니다.

## 인원관리 패널

관리자는 어느 채널에서든 아래 명령어로 봇 공통 인원을 관리할 수 있습니다.

```text
/인원관리
```

패널에서 할 수 있는 일:

- 인원 목록 확인
- 인원 추가
- 기존 인원 선택 후 수정
- Discord 유저 ID 연결

인원 수정 흐름:

1. 선택 메뉴에서 수정할 인원을 고릅니다.
2. `선택한 인원 수정` 버튼을 눌러 모달을 엽니다.
3. 기존 데이터가 채워진 모달에서 이름, 활성 여부, Discord 유저 ID를 수정합니다.
4. 저장하면 청소 추첨과 다른 기능에서 같은 인원 정보가 사용됩니다.

참고:

- 모달 안에는 버튼, 체크박스, 라디오 버튼, 선택 메뉴를 넣을 수 없습니다.
- 활성 여부는 `Y/N` 또는 `true/false` 로 입력합니다.
- Discord 선택 메뉴는 최대 25개 항목까지만 표시됩니다.
- 디스코드 유저 ID는 개발자 모드에서 유저 우클릭 후 복사할 수 있습니다.
- 스케줄 변경은 저장 즉시 현재 실행 중인 cron 예약에 반영됩니다.
- 봇을 재시작해도 저장된 스케줄을 다시 읽어 예약합니다.

## 모임 운영

채널별로 독립적인 모임을 운영합니다.

운영 흐름:

1. `/모임설정`
2. 패널에서 `모임일 설정`을 누르고 모임일 입력
3. 패널에서 `후보 추가`를 눌러 장소명, 장소 URL, 설명 입력. 후보마다 반복
4. 후보를 수정하려면 패널 아래 선택 메뉴에서 후보 선택
5. 패널에서 `투표 시작`을 누르고 투표 마감일 입력
6. 참여자는 `/참여`
7. 장소 투표는 `투표 시작`이 올린 선택 메뉴에서 선택
8. `/현황`으로 일정, 후보별 표 수, 참가자 확인

투표 메시지에서 장소를 선택하면 모임 참여도 함께 신청됩니다. 투표가 완료될 때마다 투표 메시지가 다시 갱신되어 후보별 표 수가 최신 상태로 표시됩니다.

모임설정 패널에서 할 수 있는 일:

- `모임일 설정`: 현재 채널의 모임일을 변경
- `후보 추가`: 장소 후보 추가
- `후보 초기화`: 장소 후보 전체 삭제
- `투표 시작`: 투표 마감일을 입력하고 투표 메시지 게시
- `새로고침`: 최신 모임 설정 다시 표시
- `투표 현황 리셋`: 참여자, 투표, 투표 결과 공지 기록만 초기화
- `초기화`: 현재 채널의 모임 설정 전체 초기화
- 후보 선택 메뉴와 `선택한 후보 수정`: 기존 후보 수정
